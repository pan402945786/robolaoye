# 需求与验证对应表

当前版本：V0.3。所有能力指标在有测试证据前均为目标或待定项。

## 输入与建模假设

| 参数 | 值 | 状态 |
|---|---:|---|
| 使用者质量 | 70 kg（140 市斤） | 用户确认 |
| 使用者身高 | 1750 mm | 用户确认 |
| 坐姿 / 患侧 | 能独立坐稳 / 右侧 | 用户确认 |
| 日常控制 | 乘员自行操作，无陪护操作 | 用户确认目标 |
| 样机形式 | 金属结构 | 用户确认 |
| 最大障碍 | 400 mm 单级垂直高差 | 2026-10-21 用户确认；边缘、净宽与顶面空间待测，无能力承诺 |
| 环境描述 | 标准楼梯、入户门、电梯 | 实际尺寸未知 |
| 左手操纵能力 | 未知 | 验证后才能冻结控制器 |
| 独立上设备、下设备能力 | 未知 | 单独验证 |
| 暂定设计乘员质量 | 100 kg | 沿用早期分析假设，非额定载荷声明 |
| 整机加乘员质量 | 未知 | 建立 BOM 和质量预算后确定 |
| 180 kg 总质量 | 历史分析示例 | 不由 70 kg 体重推导，不作为已确认设计值 |
| 600–700 mm 总宽 | 历史布局候选 | 门洞、操纵器和电梯包络未校核 |
| 25–35° / 130–180 mm / ≥250 mm | 历史楼梯示例 | 不是用户楼梯数据，也不是验收条件 |
| 平地、楼梯速度 | 待定 | 按稳定性、制动和控制能力决定 |

## 功能需求

| 编号 | 需求 | 验证路径 |
|---|---|---|
| FR-01 | 使用者从座位上完成方向控制、停车和模式请求 | T6：单手可达性与操作试验 |
| FR-02 | 左手操纵器为候选，右侧设可调身体和足部支撑 | T6：按功能实测，支撑由专业人员评估 |
| FR-03 | 平地低速行驶、转向、门洞和电梯通行 | T2：配重行驶与实物包络验证 |
| FR-04 | 规则楼梯首级、连续段及末级过渡 | T4/T5：配重台阶测试 |
| FR-05 | 模式切换、履带/支撑展开和调平不依赖地面人员搬动 | T4/T6：全流程单手控制验证 |
| FR-06 | 通过 400 mm 单级垂直高差为独立目标，升降动作分别建模 | M2-H / T7：环境实测、独立机构分析及专项验证 |
| FR-07 | 故障停车、原位保持及使用者可触发的求援 | T2/T5/T6：电源、控制与通信故障验证 |
| FR-08 | 转移、扣带、脚托、充电是否能自行完成 | T6：独立性清单；未完成项记录协助需求 |

## 安全需求

| 编号 | 需求 | 验证路径 |
|---|---|---|
| SR-01 | 不依赖使用者主动前倾或陪护施力维持平衡 | T4/T5：偏载、起止过渡、座椅调节工况 |
| SR-02 | 传动锁止和履带/地面整体防滑分别评估 | T4/T5：轴锁住后的整机滑移试验 |
| SR-03 | 座椅调平失效后有经校核的承载和姿态保持路径 | T1/T4：锁止及单故障试验 |
| SR-04 | 急停、松手停车、重新上电不得自动恢复运动 | T2/T6：操纵器与控制故障试验 |
| SR-05 | 楼梯边缘、偏斜和模式状态检测异常时进入已验证的安全状态 | T4/T5：丢失、误报和不同步试验 |
| SR-06 | 楼梯上不得通过手动解除制动使设备自由下滑 | T4/T5：救援工况与手动接口审查 |
| SR-07 | 无防护载人爬楼不属于当前金属原型使用范围 | 各阶段评审和试验记录 |
| SR-08 | 单侧制动、驱动或传感失效仍不得形成不可控运动 | T4/T5：冗余架构设计与故障注入 |

## 验收规则

载荷、坡度、偏斜角、制动距离、姿态误差、测试次数等通过标准和设计评审冻结，不凭概念稿任意指定。当前仅制定验证路径，尚无已完成验收项目。测试方案见安全与测试计划，原始输入见 config/design-inputs.json。

V0.3 新增 [质量预算与共面重心模型](10-engineering-baseline.md)，所有部件参数均为示例假设，不使上述验收项变为已通过；400 mm 专项尚未完成接触或运动学分析。
