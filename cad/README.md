# CAD 目录

用于保存参数化 CAD 模型、装配体、工程图和中性格式导出文件。

建议命名：

```text
RB-V01-ASM-底盘总成.step
RB-V01-PART-左履带架.step
RB-V01-PART-右履带架.step
RB-V01-PART-座椅调平平台.step
RB-V01-DWG-主车架.pdf
```

在尺寸尚未冻结前，不要把临时草图标记为正式工程图。

V0.3 提供由分析参数生成的 [SVG 布局占位图](../simulation/examples/v0.3/layout.svg)，用于讨论质量位置，不是 CAD 实体装配或可加工工程图。占位尺寸均为假设，完整乘员和展开机构包络未建模。
