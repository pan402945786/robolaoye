# 项目章程

当前需求基线：V0.2，2026-10-21；替代 V0.1 的陪护操作假设。

## 目标与使用者

为一名 70 kg、175 cm、右侧偏瘫且能独立坐稳的使用者研发载人移动底座。日常目标是不依赖陪护人员操作，通行住宅、居民楼、商场超市及街边店。独立转移能力、左手功能、视野和控制器操作能力尚未确认。

本人发出方向和模式指令，设备提供稳定、制动和动作互锁；全自主导航不属于当前已确认目标。能自行坐稳不作为能安全独立爬楼的证据。

## 范围

- 室内外低速移动；
- 门洞、通道、电梯及楼梯平台的空间适配；
- 规则楼梯的上下行及首末级过渡；
- 用户所述 40 cm 障碍的单位、形态核实与独立可行性评估；
- 使用者可达的操纵器、急停和故障求援；
- 直接制作金属验证样机。

“标准楼梯、标准门、标准电梯”仅为环境描述。结构尺寸冻结以实测为准；旋转、湿滑、破损或不规则楼梯尚未纳入验证边界。

## 研发原则

- 用户参数、假设参数和通过测试的能力分别记录；
- 先做金属台架和配重样机，再逐步载人；
- 日常无需陪护操作与试验必须有人防护可以同时成立；
- 楼梯起止过渡、侧倾和失电保持单独验证；
- 不以电机额定功率或减速机自锁推断整机防滑能力；
- 400 mm 单级障碍通过性不能由爬楼测试推断；
- 控制器、机构、安全带等必须验证单手操作的可达性；
- 故障后原位保持和求援不等于已经实现自行撤离。

## 阶段出口

1. 需求：核实障碍单位和环境尺寸，保留其他独立任务推进；
2. 布局：完成质量预算、空间包络、重心及机构动作顺序分析；
3. 金属台架：验证承载路径、制动、锁止及故障保持；
4. 配重样机：验证平地、规则楼梯、首末级过渡和故障工况；
5. 使用者测试：先受控平地，再按评审确定的边界扩大场景；
6. 独立使用评估：验证单手全流程操作、误操作恢复和救援方案。
