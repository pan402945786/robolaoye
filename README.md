# RoboLaoye

面向偏瘫使用者的载人移动底座：室内外低速行驶、障碍通行与规则楼梯通行的工程研究项目。

**当前版本：V0.2 需求更新 / 金属验证样机规划，2026-10-21。**

V0.2 将日常操作方式从陪护操作改为乘员自行操作。使用者自行发出指令与全自主导航是不同需求；当前不承诺全自主导航，也未验证无人陪同爬楼能力。

## 已知输入

| 项目 | 用户提供的信息 | 工程处理 |
|---|---|---|
| 体重 | 140 斤 | 按市斤换算为 70 kg |
| 身高 | 175 cm | 1750 mm；坐宽、腿长和控制器可达范围待测 |
| 坐姿 | 能独立坐稳 | 不等于已确认动态支撑或独立转移能力 |
| 患侧 | 右侧 | 优先评估左手操纵和右侧支撑 |
| 楼梯、入户门、电梯 | 标准 | 记录描述，不能替代实测尺寸 |
| 最大门槛 | 40 cm | 原样保留为 400 mm，待核实单位和障碍形态 |
| 日常操作 | 无陪护人员操作 | 乘员自行操作为目标，测试阶段仍需现场防护 |
| 样机 | 直接做金属结构 | 从无人载荷的金属台架和配重样机起步 |

**400 mm 障碍目前是待澄清需求，不是已实现能力。** 若确为单级垂直高差，需要独立越障机构评估，不能用楼梯爬升或小门槛测试代替。

## 当前工作顺序

1. 核实 40 cm 的单位，以及单级、连续台阶或斜坡的形态；
2. 实测楼梯、平台、门洞、电梯及人体坐姿尺寸；
3. 验证左手控制、独立转移和求援方式；
4. 建立质量预算、全工况重心模型和参数化装配布局；
5. 做金属结构和制动台架，再做配重移动样机；
6. 完成受控测试后，逐步验证乘员操作场景。

本仓库目前包含概念与验证计划，尚无可加工的结构工程图、已选定的动力系统或通过验证的载人产品。钢材规格、焊缝、轴径、减速机和制动器必须在载荷分析后确定。
