## 输入与计算定义

`design-inputs.json` 保留用户确认信息和未测量项。`layout-study.json` 中的部件质量及范围、尺寸、重心、座椅铰点、人体重心、偏移量、角度和支撑点全部是演示假设，不能作为采购或加工依据。100 kg 仍是分析载荷假设，非额定载荷。

底盘坐标为 x 向前、y 向左、z 向上，原点位于假设支撑平面中心；支撑点仅接受 z=0 平面的二维坐标。正俯仰抬高前端，正侧倾抬高左侧。底盘到世界坐标采用右手矩阵 `Ry(-pitch) Rx(roll)`；座椅组相对底盘绕给定 y 轴铰点俯仰，正角抬高座椅前端。只有 roll=0 时，`seat_pitch=-pitch` 才表示理想俯仰调平。

各部件和乘员按 `C = sum(m_i * r_i) / sum(m_i)` 求总重心。把世界竖直向下的重力方向变换到支撑坐标得 `d`，与支撑平面的交点为 `q = C - C_z / d_z * d`。对支撑点求逆时针凸包，计算 q 到各条有向边的有符号垂距，取最小值。

正裕量仅说明给定几何下重力投影在支撑区内部；外部点的负裕量不是到多边形的最短距离。本项目尚未定义可接受裕量。共面投影不能评价履带打滑、制动力矩、接触承载极限、冲击或单故障保持。

质量范围只是占位预算，上下限求和不代表置信区间；重心计算只采用名义质量。示意图里的重叠方框表示功能占位，不是实体装配或防干涉检查。控制器、乘员身体和支撑展开后的完整空间包络尚未建模，不能推断门洞、电梯通过性。

## 400 mm 单级专项：下一项机构工作

专项编号 M2-H / T7，需求对应 FR-06、SR-01、SR-02、SR-03、SR-08。当前只冻结障碍高度与单级垂直形态，没有已支持通过方向或载人能力。

先比较以下候选，以实测空间、质量增量和故障保持方案作出选择；此表不表示其中任何一种已可行：

| 候选 | 需建模的关键问题 | 必须补齐的结果 |
|---|---|---|
| 履带配前后主动摆臂 | 登沿可达性、履带与边缘接触、转轴及锁止载荷、首末接触切换 | 各动作的几何闭合、接触反力及保持路径 |
| 支腿辅助抬升与分段转移 | 支腿落点、伸缩行程、同步偏差、底盘与脚托净空 | 各阶段独立支撑、单执行器失效时的受控保持 |

不得用本次共面模型替代高低两层接触求解。应建立带真实高度的三维接触位置、法向/摩擦约束和执行器约束，逐步验证以下动作：

| 阶段 | 需确认的状态 | 本次状态 |
|---|---|---|
| H0 接近与定位 | 下层地面支撑、前方净空和边缘检测 | 待环境尺寸与动作定义 |
| H1 展开与首次登沿 | 触达 400 mm 顶面或边缘，禁止把未接触点当支撑 | 待机构几何与接触模型 |
| H2 抬升与转移 | 高低两层共同接触、重心运动、铰点和执行器受力 | 待多接触静力与运动学 |
| H3 下层接触释放 | 支撑区突变、单侧失去接触、失电保持 | 待连续序列与故障分析 |
| H4 顶面落稳与收回 | 足够顶面深度、座椅姿态、机构收回后仍稳定 | 待包络与动作模型 |
| H5 下降 | 另行定义下降动作，不从上升过程直接推断 | 待独立序列及保持分析 |

后续建模所需现场数据：障碍净宽、顶面深度、边缘形状、前后接近空间、表面材料/状态及周围侧边空隙；另需人体坐姿尺寸和左手可达区。未取得这些输入前，可以继续候选机构参数研究，但不能释放加工图。

## 验证范围

自动检查覆盖手算质量加权、座椅旋转、俯仰/侧倾及组合角度的重力投影、支撑区内外/边界、退化接触、非法输入、质量数据读取及命令行完整导出。后段与单侧接触反例应产生负裕量。

上述检查验证计算实现，不是硬件验收。全工况稳定性、真实楼梯及 400 mm 接触、结构强度、驱动制动、滑移和故障保持仍未完成。
