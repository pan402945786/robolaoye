# RoboLaoye

面向偏瘫使用者的载人移动底座：室内外低速行驶、障碍通行与规则楼梯通行的工程研究项目。

**当前版本：V0.3 参数化分析起点 / 400 mm 单级需求确认，2026-10-21。**

V0.2 将日常操作方式从陪护操作改为乘员自行操作。使用者自行发出指令与全自主导航是不同需求；当前不承诺全自主导航，也未验证无人陪同爬楼能力。

## 已知输入

| 项目 | 用户提供的信息 | 工程处理 |
|---|---|---|
| 体重 | 140 斤 | 按市斤换算为 70 kg |
| 身高 | 175 cm | 1750 mm；坐宽、腿长和控制器可达范围待测 |
| 坐姿 | 能独立坐稳 | 不等于已确认动态支撑或独立转移能力 |
| 患侧 | 右侧 | 优先评估左手操纵和右侧支撑 |
| 楼梯、入户门、电梯 | 标准 | 记录描述，不能替代实测尺寸 |
| 最大障碍 | 400 mm 单级垂直高差 | 用户已确认高度和单级形态；边缘、宽度及顶面空间待测 |
| 日常操作 | 无陪护人员操作 | 乘员自行操作为目标，测试阶段仍需现场防护 |
| 样机 | 直接做金属结构 | 从无人载荷的金属台架和配重样机起步 |

**400 mm 单级垂直高差是已确认需求，尚无通过能力验证。** 已列为 M2-H 独立越障专项，不能用楼梯爬升或小门槛测试代替。

## 当前工作顺序

1. 测量已确认的 400 mm 单级障碍：边缘、净宽、顶面深度及接近空间；
2. 实测楼梯、平台、门洞、电梯及人体坐姿尺寸；
3. 验证左手控制、独立转移和求援方式；
4. 将现有质量预算与共面重心示例替换为实测输入，补齐机构、全序列接触与装配布局；
5. 做金属结构和制动台架，再做配重移动样机；
6. 完成受控测试后，逐步验证乘员操作场景。

本仓库目前包含概念与验证计划，尚无可加工的结构工程图、已选定的动力系统或通过验证的载人产品。钢材规格、焊缝、轴径、减速机和制动器必须在载荷分析后确定。

## 运行初步分析

Python 3，仅标准库：

```powershell
python simulation/layout_study.py
python -m unittest discover -s tests -p "test_*.py" -v
```

结果写入 `simulation/results/layout-study/`，包括质量表、工况 CSV/JSON 和布局/支撑区 SVG。`config/layout-study.json` 内全部部件质量、尺寸、人体重心和接触点均为假设。模型仅处理共面支撑，不求解 400 mm 单级的高低两层接触，也不输出安全合格结论。

## 目录

- docs/：需求、方案、标准来源与测试计划；
- config/：已知输入、假设值和待确认项；
- cad/：后续 CAD、装配图和工程图；
- simulation/：质量与共面重心计算、示例结果及后续机构分析；
- prototype/：金属样机加工、BOM 和装配记录；
- tests/：验证记录与原始数据。
