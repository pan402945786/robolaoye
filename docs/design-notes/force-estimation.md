# 受力估算

> V0.2 注记：使用者实际质量已确认 70 kg；以下 180 kg 总质量与 30° 坡度是历史示例，尚未成为新样机的设计值。100 kg 乘员质量暂作为分析假设，额定载荷未确定。设备总质量需由金属车架、机构、电池等 BOM 计算。

## 1. 初始假设

- 总质量 `m = 180 kg`；
- 楼梯坡度 `theta = 30 deg`；
- 重力加速度 `g = 9.81 m/s^2`；
- 左右两条履带平均分担牵引力。

## 2. 沿楼梯方向的重力分量

```text
F_gravity = m * g * sin(theta)
           = 180 * 9.81 * sin(30 deg)
           ≈ 883 N
```

这个数值只表示克服重力的理想牵引力，不包含履带变形、楼梯边缘冲击、轴承和减速机损失、起步冲击或打滑余量。

## 3. 初步牵引力范围

V0.1 可先把两侧履带的总有效牵引力预估为 1.5–2.0 kN，再通过样机实测校核。若左右平均分担，则每侧约为 0.75–1.0 kN。

## 4. 初步输出转矩

若主动链轮半径暂按 `r = 0.10 m`：

```text
T_track = F_track * r
        ≈ 75–100 N·m per side
```

实际选型还应增加启动、冲击和控制裕量，并校核：

- 减速机连续和峰值转矩；
- 失电制动力矩；
- 主动链轮啮合；
- 履带与踏步的摩擦；
- 楼梯起步和结束时的瞬态载荷；
- 车架、铰点、轴、焊缝和紧固件的强度。

## 5. 重心和稳定性

需要分别检查：

- 平地前进和后退；
- 坡道停车；
- 楼梯起步；
- 楼梯中途停车；
- 楼梯结束；
- 楼梯平台转向；
- 患侧乘员偏移；
- 一侧驱动失效。

最终稳定性不能只凭静态图判断，应结合配重试验、倾角记录和独立防倾覆系统验证。

> 本文件用于早期估算，不是电机、减速机或结构件的最终选型依据。

## 6. V0.2 必须补充的分析

- 锁住输出轴不等于履带不会在踏步上整体滑动，需单独分析接触和保持；
- 履带平均分担只是示例，左右偏载和单故障必须单独计算；
- 1.5–2.0 kN 及 75–100 N·m 并非经过载荷组合和安全裕量论证的采购值；
- 用户已在 V0.3 确认 400 mm 单级障碍，应做每个中间姿态的接触、重心、力矩和故障分析，不能用沿斜面重力分量代替；
- 自行操作时不能依靠陪护拉力或乘员主动身体移动补偿不稳定；
- 连续、峰值、热、制动及结构冲击分别校核，机构自锁需实测。

V0.3 新增的 [质量与共面重心计算](../10-engineering-baseline.md) 可重算示例部件质量和座椅姿态；仍未求解上述 400 mm 多层接触或驱动选型。
