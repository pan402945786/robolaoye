# 金属验证样机计划

版本：V0.2。用户已指定直接制作金属结构样机。这里定义研发任务，不提供未经校核的加工尺寸。

## 样机分级

| 阶段 | 实物 | 输出和出口 |
|---|---|---|
| M0 | 金属车架、座椅接口和制动台架 | 明确承载路径、材料/焊缝记录，验证锁止与加载 |
| M1 | 带配重的平地金属底盘 | 刹停、失电、操纵器故障、门洞/电梯包络记录 |
| M2 | 加入候选履带、支撑和调平模块 | 规则台阶全过渡序列、偏载及故障保持记录 |
| M3 | 使用者交互版本 | 受保护平地单手操作与转移评估 |
| M4 | 经独立评审的楼梯测试版本 | 按试验条件逐步开展受保护载人验证 |

真实 400 mm 单级若确认，则另立 M2-H 障碍项目。M2 的爬楼测试通过不自动允许 M2-H 载人。

## 设计工作包

| 工作包 | 输入 | 交付物 |
|---|---|---|
| WP01 环境和人体 | 实际楼梯、门洞、电梯、坐姿和左手功能 | 带单位测量记录、最小空间包络 |
| WP02 质量和稳定性 | 70 kg 实际乘员，暂定 100 kg 设计乘员分析，部件质量 | 各姿态质量表、重心轨迹、支撑接触和故障姿态 |
| WP03 主车架 | WP02 的载荷组合和接口 | 材料/截面选择、连接和焊缝计算、评审图 |
| WP04 驱动与制动 | 速度、坡度、接触几何、效率及热占空比 | 连续/峰值驱动、保持和失效计算、选型依据 |
| WP05 机构 | 调平、模式转换、首末级动作 | 运动学、铰点载荷、锁止、夹点检查 |
| WP06 控制和求援 | 左手可达区、边缘/姿态检测、断电情景 | 状态表、互锁和故障响应，求援供电方案 |
| WP07 制造 | 评审通过图纸 | BOM、检验点、加工装配和变更记录 |
| WP08 验证 | 通过条件与仪器 | 原始数据、异常和逐项验收报告 |

## 制造前检查

- 实测环境和障碍形态是否已进入装配模型；
- 质量预算是否包含电池、制动器、执行器、护罩和支撑；
- 履带切换时是否存在短暂失去稳定支撑；
- 电机锁止后履带整体滑移是否单独分析；
- 起止级冲击是否有结构载荷路径；
- 制动、调平和支撑的单故障是否有保持措施；
- 用户是否能从座位操作所有日常必要接口；
- 配重楼梯试验是否具备独立锚点和经评审的防护装置。

## 关键件定型顺序

外廓、载荷、速度和机构行程冻结后，再确定履带总成、减速机、制动器、推杆和电池规格。钢管壁厚、轴径及焊缝尺寸按计算和制造能力选择，关键件以 WP04/WP05 结论为依据。
