# 项目章程

## 1. 背景

目标使用者为偏瘫患者。设备需要解决轮椅或普通助行设备在居民楼无电梯、门槛、室内外高差和非标准道路上的通行困难。

项目名称 RoboLaoye 暂作为仓库名，后续可根据产品定位重新命名。

## 2. 用户和使用场景

主要使用者：

- 偏瘫患者；
- 需要坐姿移动、但患侧控制能力不足的使用者；
- 能在陪护或护理人员帮助下完成上下设备和固定。

典型场景：

1. 从住宅室内移动到楼梯口；
2. 在平地或坡道上进入居民楼大厅；
3. 在规则直楼梯上由陪护人员操作上下楼；
4. 通过商场、超市和小店入口；
5. 在地面门槛、地砖高差和小型路沿处低速越障；
6. 在故障或断电时保持稳定并完成撤离。

## 3. 项目原则

- 先确定使用边界，再设计机构；
- 安全机构优先于轻量化和速度；
- 关键功能尽量采用机械冗余；
- 楼梯模式必须有明确的模式确认和低速限制；
- 第一版采用人工操作，不做自主爬楼承诺；
- 先用配重和假人完成测试，再进行真人测试；
- 所有关键尺寸和假设都记录在版本化文档中。

## 4. 主要风险

- 前后倾覆和侧向倾覆；
- 履带打滑、脱轨和断电后溜；
- 座椅调平机构失效；
- 患侧身体滑移或乘员弹出；
- 电池、控制器或制动器过热；
- 夹点、剪切点和卷入点伤害；
- 楼梯平台空间不足导致转向或撤离困难；
- 商场和道路环境中的碰撞风险。

## 5. 阶段出口

### 阶段 A：需求收集

完成使用者信息、楼梯尺寸、门洞尺寸、门槛高度和电梯空间测量。

### 阶段 B：概念方案

完成底盘外廓、驱动布局、座椅支撑、履带位置和防倾覆机构的参数化布局。

### 阶段 C：非载人样机

完成平地底盘、门槛越障、坡道、失电停车和机械锁止验证。

### 阶段 D：配重样机

使用配重假人完成稳定性、爬楼、防后溜和紧急撤离测试。

### 阶段 E：受控真人测试

由机械、康复或安全专业人员共同制定测试条件，逐步扩大场景。
