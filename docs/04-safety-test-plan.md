# 安全与测试计划

版本：V0.2。日常目标为乘员自行操作，研发测试仍设现场人员和独立防护。

## 试验前提

试验载荷、允许角度、速度、制动距离、姿态误差、次数及中止条件，需根据标准原文和设计评审形成书面方案。下表为任务清单，不是合格判据。金属首样先空车，再配重；真人试验在前序结果评审后开展。

安全绳或卷扬机需有独立锚点，并校核额定能力、连接点和跌落/滑移距离；有一根绳不代表具备完整防护。故障注入先在台架、空车或配重工况做，不能在载人楼梯上首次尝试。

## 分阶段验证

| 阶段 | 内容 | 重点记录 |
|---|---|---|
| T0 检查 | 焊缝、连接、销轴、护罩、电气、传感和线束 | 实际材料、紧固、缺陷及修复 |
| T1 结构 | 车架、座椅、履带和支撑锁止加载 | 载荷路径、变形与剩余变形；不预设任意试验系数 |
| T2 平地 | 行驶、差速、停车、松手、急停、掉电、重启 | 制动距离、偏航、重启不自走、掉电保持 |
| T3 小障碍 | 在已冻结高度逐级验证门槛和坡道 | 轮组抬升、冲击、侧倾和卡底 |
| T4 台架/少级台阶 | 模式切换、起止级、调平、接触丢失 | 支撑转换、全程重心、履带锁止后的整体滑移 |
| T5 配重楼梯 | 连续段、上/下、偏斜、停车、顶端过渡 | 实际坡度、表面、偏载、电流、温度、姿态和安全装置受力 |
| T6 使用者 | 先受保护平地；后续按评审决定楼梯试验 | 左手全流程操作、右侧支撑、视野、误操作及求援 |
| T7 400 mm 专项 | 仅在单位和障碍形态确认后立项 | 单级/连续台阶/坡道分别设计，不与 T3 混用 |

## 单故障与异常

- 主电源或控制供电失效、低电量及负载压降；
- 一侧驱动失效、编码器信号异常或左右速度不一致；
- 一侧制动器失效，评估剩余保持路径；
- 履带打滑、脱轨或传动链断开；
- 姿态/边缘传感丢失、误报或不同步；
- 调平执行器故障、锁止失败或支撑展开不到位；
- 摇杆卡住、信号断线、重启、急停和通信丢失；
- 在规定范围内的乘员偏载、脚托/支撑变更；
- 故障后保持位置、求援、救援固定和撤离。

所有故障的响应顺序都需基于支撑与承载设计确定。楼梯上不能先随意释放制动或断开承重执行器，再依赖人扶住。

## 乘员自行操作专项

1. 评估左手持续握持、松开、到达急停和模式切换能力；
2. 评估坐姿视野以及后退接近楼梯时的辅助观察；
3. 评估能否自行转移、扣带、收放脚托及充电；
4. 不要求用右手或身体重心补偿机构不稳定；
5. 故障后无需站起即可求援；全机失电和无网络情况下的备用途径待定；
6. 记录哪些任务仍需外部协助；完成前不得宣称全流程独立使用。

## 原始记录

每份记录包含日期、版本、工况尺寸和表面、载荷与分布、操作者、仪器、动作顺序、原始数据、照片/视频索引、异常和中止原因。试验结果与 FR/SR 编号关联存入 tests/。
