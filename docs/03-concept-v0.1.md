# V0.1 总体结构方案

> 历史方案：2026-10-21 更新为 V0.2。本文陪护操作等假设不再作为当前需求，当前架构见 [V0.2 概念方案](07-concept-v0.2.md)。原文保留用于追溯。

## 1. 方案概述

V0.1 采用模块化双模式底盘：

1. 平地模式使用左右独立驱动轮组；
2. 楼梯模式展开左右橡胶履带；
3. 座椅安装在可调平平台上；
4. 前后设置防倾覆支撑和辅助滚轮；
5. 座椅和底盘分开设计，便于更换不同身体支撑模块。

## 2. 主承载底盘

主车架采用左右对称的矩形承载框架，核心部件集中在低位：

- 电池仓位于底盘下部中央；
- 控制器位于防水、防碰撞的侧舱；
- 座椅安装点位于左右承载梁之间；
- 后方保留推行杆和人工拖移接口；
- 车架预留吊点，但吊点必须独立校核。

原型阶段优先考虑可修改的焊接钢结构。尺寸冻结后再进行轻量化设计。

## 3. 平地驱动

每侧包括：

- 驱动电机和减速机；
- 主驱动轮；
- 前后辅助轮；
- 独立失电制动器；
- 轮速或编码器；
- 防倾覆小轮。

建议先采用差速转向。平地模式的速度、加速度和转向角应受到软件限制，并保留机械急停。

## 4. 爬楼履带

每侧履带模块包括：

- 橡胶履带；
- 主动链轮；
- 张紧轮；
- 承重轮；
- 导向轮；
- 减速电机；
- 机械张紧和防脱轨结构；
- 履带架展开铰点；
- 展开状态机械锁。

履带模块进入楼梯模式后，主车架与履带架之间必须形成明确的承载路径，不能只依靠电动推杆承载楼梯冲击。

## 5. 座椅调平

座椅平台采用一侧或两侧平行四边形连杆，配合电动推杆完成俯仰调平。设计要点：

- 具备机械上下限位；
- 调平完成后能够机械锁止；
- 有角度传感器和故障报警；
- 断电时保持当前姿态；
- 不允许调平机构成为唯一的防翻倒结构。

## 6. 身体支撑

座椅模块应独立于底盘设计，至少包括：

- 可调靠背；
- 骨盆固定带；
- 胸部或肩部固定带；
- 患侧躯干支撑；
- 患侧膝部限位；
- 双脚脚托和足部固定；
- 可翻转扶手；
- 快速释放结构。

具体束缚方式应由康复或护理专业人员参与评估。

## 7. 控制模式

### 模式 A：普通行驶

速度和转向灵敏度适合室内环境，支持前进、后退、左右差速转向。

### 模式 B：慢速越障

限制速度和加速度，允许通过已经验证的门槛和地面高差。

### 模式 C：楼梯

进入前需要人工确认：

- 履带已展开；
- 防倾覆支撑已到位；
- 座椅安全带已锁定；
- 座椅调平机构状态正常；
- 楼梯条件在允许范围内。

## 8. 主要接口

后续 CAD 需要固定以下接口：

- 座椅安装孔位；
- 电池仓尺寸；
- 左右电机安装面；
- 履带架铰点；
- 防倾覆支撑转轴；
- 推行杆；
- 吊点；
- 控制器和急停按钮；
- 充电口和主电源开关。
