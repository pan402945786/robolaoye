# 安全与测试计划

## 1. 测试原则

所有楼梯测试先使用空车、沙袋或配重假人。真人测试必须在独立安全绳、卷扬机或等效防护条件下进行，并由现场负责人决定是否继续。

## 2. 测试阶段

### T0：结构检查

- 检查焊缝、螺栓、销轴和轴承；
- 检查履带张紧和防脱轨；
- 检查座椅、脚托和安全带；
- 检查机械限位和急停；
- 检查电池、保险和线束固定。

### T1：静态载荷

- 在水平地面加载目标总质量；
- 检查车架变形；
- 检查座椅安装点；
- 检查支撑轮和履带架铰点；
- 记录永久变形和异常声响。

### T2：平地移动

- 前进、后退和差速转向；
- 低速刹停；
- 坡道起步和停车；
- 断电后的制动；
- 单侧驱动故障模拟。

### T3：门槛和小障碍

- 从两个方向通过目标门槛；
- 低速重复通过；
- 检查座椅冲击和乘员支撑；
- 检查驱动轮打滑和车架扭转。

### T4：楼梯准备

- 水平试验台模拟履带接触；
- 验证履带展开、锁止和收回；
- 验证座椅调平；
- 验证前后防后溜；
- 验证断电保持；
- 验证安全绳和人工撤离。

### T5：配重楼梯

- 由低坡度、少级数开始；
- 使用配重假人模拟乘员；
- 每次只改变一个变量；
- 记录履带速度、电流、倾角和滑移；
- 测试上楼、下楼、起步、结束和中途停车。

### T6：受控真人

只有 T0–T5 完成并由有资质人员确认后才能进行。真人测试应从平地和低风险场景开始，逐步增加楼梯和障碍条件。

## 3. 关键故障注入

- 主电源断开；
- 左侧驱动失效；
- 右侧驱动失效；
- 角度传感器异常；
- 履带展开不到位；
- 防倾覆支撑未锁止；
- 控制器过温；
- 急停触发；
- 低电量保护。

## 4. 记录文件

每次测试应保存：

- 测试记录表；
- 配置照片；
- 视频；
- 电机电流和速度数据；
- 倾角数据；
- 故障描述；
- 修复或变更记录。

测试记录放在 `tests/`，结构变更同步更新 `docs/` 和版本号。
