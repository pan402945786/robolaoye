# RoboLaoye

载人越障移动底座项目，面向偏瘫患者的室内外移动、门槛越障和规则直楼梯辅助通行。

> 当前阶段：V0.1 概念方案与需求冻结前整理
>
> 安全边界：本仓库的内容用于工程设计、讨论和样机规划，不能直接作为载人设备制造图纸。任何载人测试都必须在完成结构强度、稳定性、制动、失电停车和紧急撤离验证后，由合格工程人员现场负责。

## 项目目标

设计一套模块化载人底座，使偏瘫患者能够在陪护人员操作下完成：

- 室内外平地低速移动；
- 通过居民楼、商场、超市和街边店的普通通道；
- 通过门槛、地面高差和小型路沿；
- 在规则、干燥、直线楼梯上低速上下楼；
- 在断电、驱动故障和紧急情况下保持或安全撤离。

## V0.1 设计边界

第一版只针对以下环境：

- 一名乘员；
- 有陪护人员操作；
- 直线、规则、干燥楼梯；
- 楼梯踏步高度约 130–180 mm，踏步深度不小于约 250 mm；
- 暂不支持旋转楼梯、弧形楼梯、湿滑楼梯、镂空楼梯和台阶高度严重不一致的楼梯；
- 暂不追求无人自主爬楼。
